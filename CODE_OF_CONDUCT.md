# Code of conduct

Billboard follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text is at that link. It applies here as written, to everyone who takes part, the project's maintainers
included. In the Covenant, "community leaders" means the project's maintainers.

## Where it applies

- The project's repositories on GitHub, `billboard-backend` and `billboard-ios`: issues, pull requests, reviews,
  discussions, commit messages and any other comments.
- Any other space the project runs for contributors, and anyone speaking for the project in public.

## How to report

Email **contact@billboard-project.com** with "Conduct" in the subject. Do not report conduct problems in a public
issue. You can also report content to GitHub itself, with **Report content** on any comment.

The project's maintainers read these reports and keep them private. They decide what to do using the Covenant's
enforcement guidelines (correction, warning, temporary ban, permanent ban), and they reply to you.
